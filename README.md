# Car Dealership Finder

A full-stack web application that helps users find car dealerships 
based on location and understand customer experiences through
AI-powered sentiment analysis.

## Overview

Car Dealership Finder allows users to search for car dealerships,
view dealership information, and submit customer reviews.

The application integrates **IBM AI Sentiment Analysis** to
automatically classify customer reviews into **positive, neutral,
or negative** sentiments. This helps users better understand
previous customer experiences when evaluating dealerships.

## Features

- Search for car dealerships based on location.
- View dealership information.
- Submit customer reviews.
- Analyze customer reviews using IBM AI Sentiment Analysis.
- Classify reviews as positive, neutral, or negative.
